# BatteryPulse v2.2.4

## 程序耗能排行補漏

- 改為每秒擷取一次程序 CPU 使用率，保留最近五秒的樣本。
- 以五秒內每秒使用率累加成活動分數，再換算前五名比例。
- 前五名以外的程序合併為「其他」，避免長期低占用程序被錯誤放大。
- 顯示占比與依目前整機功耗按比例估算的瓦數；這是分配估算，不是程序獨立電表讀值。
- 不把整體 GPU 使用率假分配到個別程序；排行來源會在頁面下方明確標示。
- 保留既有電池、整機功耗、溫度與充電限制讀取方式。

## 驗證狀態

- C# 主程式編譯成功。
- `git diff --check` 通過。
- 執行檔版本資訊為 `2.2.4.0`。
- 本環境啟動新程序受到權限限制，未能完成互動式啟動測試；需在 Windows 桌面手動開啟後確認五秒取樣排行。
