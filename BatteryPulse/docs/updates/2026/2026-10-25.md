# BatteryPulse 2.2.2.6

## Codex 額度狀態列

- 頂端列加入一組 Codex 標示與「剩餘百分比／窗口」數值，格式如 `72/5H  91/W`；`5H` 表示五小時，`W` 表示每週。
- 從本機已登入的 Codex 讀取帳戶額度，分別使用 300 分鐘與 10080 分鐘窗口，避免將其他種類的額度誤認為這兩個數字。
- 背景約每 60 秒查詢一次，查詢完成後關閉輔助程序；查詢失敗會降低重試頻率。程式不儲存或顯示登入憑證，無法取得數值時顯示 `--`。
- Codex 顯示項目可在進階儀表的頂端列設定中隱藏或調整排序。
- Codex 標示改為隨本機 Codex 程式提供的單色透明圖標，沒有外框、陰影或強調色；五小時額度右側顯示本機時間的 24 小時制重置時刻（`HH:mm`）。
- Codex 圖標改用與既有閃電圖標相同的 11 像素高度與垂直位移，避免比文字大或偏離同一行。
- 五小時重置時間左側加入 11 像素雙箭頭更新圖示，與 Codex 圖標同尺寸、同垂直位移，無外框、陰影或底色。
- 充電瓦數、系統功耗及其他即時數字使用固定欄寬、等寬數字及靠右排列；數字變動不再推動整條置中狀態列。
- 跨螢幕定位先將視窗移到目標螢幕，待該螢幕的 DPI 套用後再依其解析度置中；從進階儀表板返回不會因滑鼠位置而改放另一台螢幕。
- 頂端列視窗與文字容器不再鋪設半透明白色底，避免深色畫面背後出現整條較亮的矩形邊界。

額度由服務端計算，這裡顯示最近一次取得的數值，不保證逐秒變動。
