# BatteryPulse 2.2.2.2

## 小改版更新

- 頂端狀態列改為完全穿透滑鼠，不再攔截瀏覽器分頁、關閉按鈕或其他視窗操作。
- 右下角通知區的 Battery Pulse 圖示左鍵開啟進階儀表板，右鍵保留選單功能。
- 增加托盤開啟流程的初始化等待與防重複觸發，降低點擊後沒有畫面的情況。
- GPU 使用率優先採用 Core／3D 來源，排除記憶體、Copy、影音引擎造成的誤判高使用率。
- 執行診斷日誌依錯誤來源分別限頻，降低異常狀態下持續寫入硬碟的機會。

## 驗證

- 已重新編譯 `BatteryPulse.TopBar.exe`。
- 已確認輸出檔案版本為 `2.2.2.2`。
- 已以無啟動註冊參數啟動測試程序並確認程序保持運作。

本版本仍由使用者透過 GitHub Release 頁面主動取得更新，不會自動下載或覆蓋檔案。
